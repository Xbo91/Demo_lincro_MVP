# Lincro Demo Website

A responsive static website built using **HTML**, **CSS**, and **JavaScript** as part of my Web Development coursework.

> This project is a demo version of **Lincro**, a startup idea I am developing to connect users with skilled professionals for everyday services.

## Project Overview

Lincro is a service marketplace concept that helps users quickly find skilled workers for daily tasks such as:

- Plumbing
- Home Cleaning
- Electrical Repairs
- Vehicle Repair

This demo recreates the landing page of the original Lincro website using only front-end technologies.

---

## Features

- Responsive navigation bar
- Mobile hamburger menu
- Hero section with animated glow effects
- Blurred background using CSS
- Interactive search bar
- Service category buttons
- Animated "I Need Help Now" CTA
- Hover animations
- Smooth transitions
- Responsive layout
